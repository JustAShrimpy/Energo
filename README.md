# EnergoBel — Энергетика Беларуси

Образовательный веб-ресурс об энергосбережении и энергетике Беларуси. Проект создан в рамках Энергомарафона.

**Сайт проекта:** [https://justashrimpy.github.io/Energo/](https://justashrimpy.github.io/Energo/)

## Инструкции по запуску

### Требования

- Node.js 18+
- npm

### Установка зависимостей

```bash
npm install
```

### Локальный запуск

```bash
npm run dev
```

Сервер Vite запустится, как правило, на `http://localhost:5173`.

### Production-сборка

```bash
npm run build
```

Результат сборки появится в каталоге `dist/`. Базовый путь задан в `vite.config.js` как `/Energo/`.

### Проверка линтером

```bash
npm run lint
```

## Особенности реализации интерактивных элементов

### Калькулятор расхода электроэнергии (`Calculator.jsx`)

- Позволяет добавлять, удалять и настраивать список бытовых приборов.
- Рассчитывает дневной и месячный расход в кВт·ч, стоимость в BYN и выбросы CO₂.
- Потенциальная экономия рассчитывается на основе снижения потребления на 30%.
- Использует `useMemo` для оптимизации вычислений и `useState` для управления списком приборов.

### Экоквиз (`Quiz.jsx`)

- Сохраняет текущий вопрос и счёт в `localStorage`, чтобы пользователь мог продолжить позже.
- Реализует обратную связь по ответу: правильный/неправильный вариант выделяется цветом.
- Использует `useState` и `useEffect` для управления состоянием и сохранения прогресса.

### Энергоигра (`EnergyGame.jsx`)

- Интерактивная мини-игра: пользователь выключает ненужные приборы, не трогая необходимые (холодильник, роутер).
- Счёт зависит от количества правильных действий и штрафа за ошибки.
- Генерация раунда происходит случайным образом с помощью `Math.random`.

### Карта энергетики (`EnergyMap.jsx`)

- SVG-контур Беларуси с интерактивными точками по областям.
- При выборе области отображается список электростанций с указанием типа и мощности.
- Реализована доступность через `role="group"`, `aria-label` и `aria-pressed`.

### Сравнение ламп (`ComparisonSlider.jsx`)

- Визуальное сравнение лампы накаливания 60W и LED 10W по энергопотреблению, сроку службы и годовой экономии.

### Чек-лист энергосбережения (`Checklist.jsx`)

- Список практических действий с сохранением выполненных пунктов в `localStorage`.
- Отображает прогресс в процентах.

### Слайдер появления секций (`Reveal.jsx`)

- Обёртка на основе `IntersectionObserver`.
- Секции плавно появляются при попадании в область видимости.

## Использованные CSS-свойства

- **CSS Custom Properties (`var(...)`)** — централизованное управление цветами, типографикой и отступами, поддержка тёмной/светлой темы.
- **`display: flex` / `grid`** — раскладка компонентов и карточек.
- **`@media` queries** — адаптивная вёрстка.
- **`transition`, `animation`, `@keyframes`** — плавные появления, hover-эффекты, анимированные числа.
- **`transform`** — перемещение и масштабирование элементов интерфейса.
- **`backdrop-filter: blur(...)`** — стеклообразный фон шапки.
- **`position: sticky`** — фиксация заголовка при скролле.
- **`clamp()`** — адаптивная типографика.
- **`overflow: hidden`, `object-fit: cover`** — корректное отображение медиа-контента.

## Использованные JavaScript-методы и API

- **React Hooks:** `useState`, `useEffect`, `useRef`, `useMemo`, `useContext`.
- **React API:** `lazy`, `Suspense` — ленивая загрузка секций; `createContext`, `Provider` — управление глобальным состоянием темы и языка.
- **Web API:**
  - `IntersectionObserver` — анимация появления секций и запуск счётчиков.
  - `localStorage` — сохранение языка, темы, прогресса квиза и чек-листа.
  - `requestAnimationFrame` + `performance.now()` — плавная анимация чисел.
  - `Intl` — не используется напрямую; форматирование выполняется через `toFixed`.
- **Встроенные методы:** `map`, `filter`, `reduce`, `find`, `Math.min`, `Math.max`, `Math.random`, `JSON.parse` / `JSON.stringify`.

## Библиотеки

- `react` — библиотека для построения пользовательского интерфейса.
- `react-dom` — рендеринг React-приложения в браузере.
- `vite` — инструмент сборки и dev-сервера.
- `oxlint` — линтер для проверки качества кода.

Внешние UI-библиотеки, CSS-фреймворки и шрифты не используются.

## Обоснование темы и визуальных решений

**Цветовая тема:** проект использует тёмную палитру с зелёными и электрическими акцентами. Тёмный фон ассоциируется с ночью/энергосбережением и снижает нагрузку на глаза при длительном просмотре. Зелёный цвет символизирует экологию, чистую энергию и устойчивое развитие.

**Визуальные эффекты:** анимированные частицы и фоновые эффекты создают ощущение энергии и движения, что соответствует теме электроэнергии. Плавные появления секций делают путь пользователя по сайту динамичным и целостным.

**Типографика и интерфейс:** минималистичный дизайн, чёткая иерархия, крупные счётчики и карточки помогают быстро воспринимать ключевые данные о генерации и экономии энергии.

**Мультиязычность и темизация:** поддержка русского и белорусского языков, а также переключение между тёмной и светлой темами, делает ресурс доступным для разных пользователей и устройств.

# EnergoBel

Сайт про энергосбережение в Беларуси, созданный для областного IT-рейтинга.

## Возможности

- Информационный Hero-блок
- Анимированные факты и цифры
- Раздел «Зачем экономить энергию»
- Интерактивный калькулятор расхода электроэнергии
- Карточки с советами
- Экоквиз

## Стек

- React 19
- Vite 8
- CSS3

## Установка и запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

Сборка появится в папке `dist/`. Загрузите содержимое `dist/` на ваш сервер.

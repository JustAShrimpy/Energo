# План: Энергосбережение в Беларуси

## Цель
Создать красивый, динамичный React-сайт про энергосбережение в Беларуси для IT-рейтинга.

## Стек
- React 19
- Vite 8
- CSS3 с анимациями
- Без бэкенда (статичный сайт)

## Структура
1. Header — логотип + навигация
2. Hero — заголовок, анимированный фон, CTA
3. Facts — статистика Беларуси с анимированными счётчиками
4. Why — почему важно экономить энергию
5. Calculator — интерактивный калькулятор экономии
6. Tips — карточки с лайфхаками
7. Quiz — небольшой квиз
8. Footer — контакты

## Размещение
Собственный сервер пользователя. Сборка `npm run build` создаёт `dist/`, который загружается на сервер.
